# 零醛 · 技术实录（博客源码）

本站用Jekyll（静态站点生成器）构建，托管在GitHub Pages，推送到main分支即自动上线，地址：https://lingquan11.github.io

## 内容架构（定版）

- 纯技术博客，只设两栏：**项目实录**、**深研自述**
- 内容红线：每篇必须含代码、公式、数据、原理拆解中的至少两样，非技术内容不进站
- 单篇六段模板：问题与背景、核心原理、实现或推导、数据与验证、踩坑与边界、参考来源

## 怎么发新文章

1. 在`_posts/`目录新建文件，命名格式：`YYYY-MM-DD-英文短标题.md`
2. 文件头固定写：

```yaml
---
layout: post
title: "文章标题"
date: YYYY-MM-DD HH:MM:SS +0800
categories: 项目实录
---
```

分类只用「项目实录」或「深研自述」。

3. 正文用Markdown写，公式用`$$...$$`（行间）或`$...$`（行内），代码块标语言名
4. 提交并推送，约1分钟后上线

## 写作规矩（本人定）

- 只写真做过的，没想通的把卡点原样写出来
- 性能数字标机器、尺寸、测法，能复现才算数
- 一周一篇左右，不断更优先于写得长
